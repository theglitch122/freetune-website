Updates

Already have the app? Download the newest update for your device. Everything you've saved is kept.

Windows

Save the .update file into your Downloads folder. FreeTune notices it within a few seconds and shows Restart and update. Or use Settings → Updates → Install update file.

Android

Open the new APK and tap Update. It installs over your current app.

iPhone

Install the new IPA with Sideloadly or AltStore, the same way as the first time.
